# Skypro.Wallet

**Skypro.Wallet** — это веб-приложение для учета личных расходов.  
Сервис позволяет пользователю добавлять расходы, просматривать список трат, выбирать период и анализировать расходы по категориям.

## Создатели проекта

Проект разработали:

- **Оля**
- **Кирилл**

## Описание проекта

Skypro.Wallet создан как учебный командный проект на React.  
Приложение сверстано и доработано по макету, с учетом адаптивности для разных экранов.

В проекте реализованы страницы авторизации, регистрации, списка расходов, добавления нового расхода и анализа расходов.

## Основной функционал

В приложении есть:

- регистрация пользователя;
- вход в аккаунт;
- выход из аккаунта;
- просмотр таблицы расходов;
- добавление нового расхода;
- редактирование существующего расхода;
- удаление расхода;
- выбор категории расхода;
- выбор даты;
- фильтрация по периоду;
- анализ расходов по категориям;
- диаграмма расходов;
- адаптивная верстка;
- состояния ошибок в формах;
- активные состояния полей ввода и кнопок.

## Страницы приложения

### Вход

Страница входа содержит форму авторизации:

- поле для электронной почты;
- поле для пароля;
- кнопку входа;
- ссылку на страницу регистрации;
- отображение ошибок при неверных данных.

### Регистрация

Страница регистрации содержит форму создания аккаунта:

- поле имени;
- поле электронной почты;
- поле пароля;
- кнопку регистрации;
- ссылку на страницу входа;
- валидацию полей и отображение ошибок.

### Мои расходы

На странице «Мои расходы» отображаются:

- таблица расходов;
- список трат;
- категории;
- даты;
- суммы;
- кнопка удаления;
- форма добавления нового расхода.

### Новый расход

Форма нового расхода позволяет заполнить:

- описание;
- категорию;
- дату;
- сумму.

Если данные введены некорректно, поля подсвечиваются, а кнопка становится неактивной.

### Анализ расходов

На странице анализа расходов доступны:

- выбор периода;
- календарь;
- отображение общей суммы расходов;
- диаграмма расходов по категориям.

## Установка и запуск

Чтобы запустить проект локально, нужно перейти в папку проекта, где находятся файлы `package.json`, `src` и `index.html`.

Затем выполнить команды:

```bash
npm install
npm run dev
```

После запуска Vite покажет ссылку, по которой проект можно открыть в браузере.

Обычно это:

```text
http://localhost:5173/
```

## Сборка проекта

Для создания финальной сборки используется команда:

```bash
npm run build
```

Для предварительного просмотра сборки:

```bash
npm run preview
```

## Важно

Запускать команды нужно не из внешней папки архива, а именно из папки проекта, где лежит `package.json`.

Правильно:

```text
SkyproWallet-main/
├── package.json
├── index.html
├── src/
└── public/
```

Неправильно запускать проект из папки, где нет полноценного `package.json` со скриптом `dev`.
