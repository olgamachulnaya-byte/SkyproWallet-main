# Skypro Wallet — stage 1

В этой версии оставлены:
- авторизация и регистрация;
- приватные роуты после входа;
- выход из аккаунта;
- верстка страниц «Мои расходы» и «Анализ расходов».

Убрано из активного проекта:
- получение расходов с API;
- добавление, редактирование и удаление расходов;
- фильтрация и сортировка;
- календарная фильтрация;
- валидация формы расхода;
- обработка ошибок формы расхода.

Запуск:
```bash
npm install
npm run dev
```
